# Vehicle Diagnostics Complete

قاعدة بيانات منظمة لتشخيص المركبات، الشركات والطرازات، أكواد DTC، والأنظمة الأساسية.

> هذه الدفعة تنشئ **نواة بيانات قابلة للتوسعة** وليست بديلاً عن كتيبات الصيانة الرسمية أو مخططات المصنع. يجب التحقق من رقم الجزء وإجراءات السلامة قبل أي إصلاح.

## المحتويات

- `data/years.csv`: طبقات السنوات 2014–2026.
- `data/brands.csv`: الشركات ومعرفاتها القياسية.
- `data/models.csv`: الطرازات وربطها بالشركات ونطاق السنوات.
- `data/vehicle_systems.csv`: أنظمة المحرك وABS وECU والتكييف.
- `data/dtc_codes.csv`: أكواد DTC عامة مع النظام والأعراض وخطوات الفحص الأولية.
- `data/wiring_diagrams.csv`: مخططات نصية أساسية ومسارات الإشارة والطاقة.
- `schemas/vehicle-diagnostics.schema.json`: مخطط JSON للتحقق من السجلات.

## قواعد المعرفات

- الشركة: `BR-XXX`، مثل `BR-TYT`.
- الطراز: `MD-XXX-000`، مثل `MD-TYT-001`.
- النظام: `SYS-ENG`، `SYS-ABS`، `SYS-ECU`، `SYS-HVAC`.
- كود العطل: يحتفظ بصيغته القياسية مثل `P0300` أو `C0035`.
- السنوات تستخدم أرقاماً صحيحة بين 2014 و2026، ويمكن تمثيل النطاق في `models.csv`.

## الاستيراد إلى Excel

افتح أي ملف CSV بترميز **UTF-8**، واختر الفاصل `,`. الملفات مصممة لتعمل مع Excel وLibreOffice وPower BI وقواعد البيانات.

## التوسعة القادمة

يمكن إضافة أرقام المحركات، الأسواق، ناقل الحركة، موصلات ECU، pinout موثق، وملفات صور SVG بعد توفير مصدر موثوق لكل سجل.
